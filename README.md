# 📈 자산 및 배당금 통합 관리 플랫폼 (Asset & Dividend Tracker)

본 애플리케이션은 사용자의 소중한 투자 자산(주식, ETF 등)과 배당금 흐름을 한눈에 관리하고 예측할 수 있도록 설계된 **웹 기반 자산 포트폴리오 관리 플랫폼**입니다. 

기존의 정형적인 데이터 입출력 방식에서 탈피하여, 모바일 환경에 최적화된 **접이식(Collapsible) 아코디언 카드형 입력 UI**와 **반응형 대시보드 시각화 차트**를 적용하여 어떤 디바이스 환경에서도 유려하고 정밀한 자산 관리 경험을 제공합니다.

---

## 🛠️ 1. 시스템 구성 (System Architecture)

본 플랫폼은 서버 지연 없는 즉각적인 사용자 피드백과 견고한 데이터 무결성을 목표로 최신 모던 프런트엔드 기술 스택으로 설계되었습니다.

### 1-1. 기술 스택 (Tech Stack)
* **Core Framework:** `React 19` (Functional Components, Hooks)
* **Language:** `TypeScript 5.8` (정적 타입 지원 및 데이터 타입 정의 강화)
* **Build Tool:** `Vite 6` (초고속 HMR 및 최적화 빌드 시스템)
* **Styling Engine:** `Tailwind CSS v4` (`@tailwindcss/vite` 플러그인을 활용한 순수 CSS 컴파일 및 반응형 유틸리티 설계)
* **Animation Library:** `Motion` (아코디언 개폐, 모달 전환, 스무스 슬라이드)
* **Data Visualization:** `Recharts 3.8` (컴포넌트형 SVG 반응형 금융 차트 엔진)
* **Data Management:** `LocalStorage` (클라이언트 사이드 영구 지속성 데이터 가상 엔진)
* **Utilities:** 
  * `lucide-react`: 모던 벡터 아이콘 에셋
  * `xlsx`: 포트폴리오 엑셀 일괄 내보내기/가져오기 기능 지원
  * `date-fns`: 자산 변동 타임라인 분석용 날짜 유틸리티

### 1-2. 시스템 구조 및 데이터 흐름
```
[사용자 브라우저]
       │
       ▼
 ┌───────────┐       (Event)       ┌────────────────────────┐
 │ React UI  │ ──────────────────> │ State Manager (Context)│
 └───────────┘                     └────────────────────────┘
       │                                       │
       │ (데이터 렌더링)                        │ (상태 변경 및 계산)
       ▼                                       ▼
 ┌───────────┐                       ┌────────────────────────┐
 │ Recharts  │ <──────────────────── │   LocalStorage Engine  │
 └───────────┘                       └────────────────────────┘
```
1. **무상태 연산 흐름:** 입력받은 수량, 현재가, 평단가는 앱 내 비즈니스 로직(Pure Functions)을 통해 실시간으로 평가금액, 평가손익, 총배당금, 배당률(Yield)로 유기적으로 자동 환산됩니다.
2. **로컬 지속성 파이프라인:** 모든 계좌 및 종목 데이터 트랜잭션은 상태가 갱신되는 즉시 클라이언트 브라우저 내의 안전하게 격리된 `LocalStorage` 영역에 실시간 쓰기 작업이 이루어집니다.

## 🚀 2. 설치 및 시작 가이드 (Getting Started)

### Prerequisites
* **Node.js:** v18.0.0 이상 권장
* **npm:** v9.0.0 이상 권장

### Installation
1. 프로젝트 소스코드를 복사(Clone) 또는 다운로드합니다.
2. 루트 디렉터리에서 필요한 의존성 패키지를 설치합니다.
```bash
npm install
```

### Running in Development Mode
개발 서버를 로컬 3000 포트에서 실행합니다. (HMR 지원)
```bash
npm run dev
```
브라우저에서 `http://localhost:3000`으로 접속하여 즉시 사용할 수 있습니다.

### Production Build & Compile
프로덕션 환경을 위해 정적 파일로 번들링하고 소스코드를 컴파일합니다.
```bash
npm run build
```
빌드 산출물은 `/dist` 폴더에 생성됩니다.

## 📱 3. 기능 구성 및 사용법 (Features & How to Use)

### 3-1. 자산 및 배당금 기록하기 (기록하기 탭)
계좌별로 투자 종목을 자유롭게 입력하고 편집할 수 있습니다.

1. **계좌 추가:** 상단의 '계좌 추가' 버튼을 눌러 종합계좌, 연금저축, ISA 등 자신만의 자산 주머니를 생성합니다.
2. **종목 추가:** 생성된 계좌 카드 하단의 `+ 종목 추가` 버튼을 클릭하여 입력 카드를 즉시 마운트합니다.
3. **스마트 아코디언 카드 조작:**
   * **기본 뷰 (접힌 상태):** **종목명**, **현재가**, **보유수량**, 실시간 연산된 **평가액 (현재가 × 수량)**이 간결하게 노출됩니다.
   * **확장 뷰 (펼쳐진 상태):** 카드를 가볍게 터치하면 서랍식 슬라이드가 열리며 **평단가**, **배당금**, **삭제(🗑️)** 옵션이 상세하게 나타납니다.
   * **입력 제어:** 인풋을 수정해도 카드 자체가 닫히지 않도록 이벤트 버블링(`stopPropagation`) 제어가 설계되어 있어 안심하고 타이핑할 수 있습니다.
4. **천 단위 회계 쉼표:** 모든 금액 입력 시 `toLocaleString()` 포맷터가 실시간 적용되어 한눈에 정돈된 숫자로 시각화됩니다.

### 3-2. 반응형 대시보드 분석 (홈 탭)
포트폴리오 비중, 배당 예측, 미래 현금흐름 등을 정밀 차트로 감상합니다.

* **자산 및 배당금 추이 그래프:**
  * **전체화면(Fullscreen) 토글:** 차트 영역 우측 상단의 `[전체화면]` 버튼을 클릭하면 화면 전체에 가득 찬 시원한 차트가 제공됩니다.
  * **X축 스마트 3단계 생략 포맷터:**
    * **세로 뷰(모바일):** 좁은 화면에서 라벨이 겹치지 않게 연도 전환점 위주로 간소화 표기(`'25`, `'26`).
    * **가로/상세 뷰(PC):** 새해 첫달(1월)에는 연도-월(`'25.1`)을 명시하고, 나머지 달에는 연도를 과감히 생략하고 순수 월 숫자(`2`, `3`, `4`...)만 표기하여 최적의 공간 배치를 선보입니다.
  * **배당금 상단 라벨 지능형 제어:** 모바일 세로 뷰에서는 차트 가독성을 망치던 바 상단의 금액 텍스트가 자동 숨김 처리되며, 가로/확장 모드에서만 나타나 도표 해석의 편리함을 더합니다.

### 3-3. 엑셀 백업 및 복원 (설정 탭)
* **백업하기:** 현재 기록된 모든 자산 및 배당금 상태를 엑셀 파일(`.xlsx`)로 다운로드하여 로컬에 물리적으로 영구 격리 백업할 수 있습니다.
* **불러오기:** 백업된 엑셀 파일을 업로드하여 언제든 동일한 자산 환경을 원클릭 복구할 수 있습니다.

## 🛠️ 4. 모바일 최적화 및 최근 UI/UX 리팩토링 상세

본 리포지토리에는 최근 모바일 환경 특성에 부합하기 위해 아래와 같은 극도의 최적화 로직이 수립되었습니다.

### 4-1. 세로 모드(max-width: 768px) 최적화
* **삭제 버튼 터치 오동작 원천 차단:** 좁은 리스트를 스크롤 하다가 우발적인 삭제 터치가 발생하지 않도록 모바일 세로 모드에서는 **삭제 버튼(🗑️)을 완전 미노출(`display: none`)** 처리했습니다. 종목 제거를 원할 경우 화면을 가로로 돌려 가로 뷰 환경에서만 안전하게 조작할 수 있습니다.
* **1글자 초소형 가변 레이블 시스템:** "평단가:", "배당금:" 레이블이 점유하던 넓은 영역을 모바일 환경 한정으로 **"평:"**, **"배:"**라는 단축 문자로 자동 스위칭시킵니다.
* **숫자 영역 풀-노출:** 가변 레이블 전환 덕분에 대규모 자산을 보유한 고액 투자자라 하더라도 수치 뒤에 생략 기호(`...`)가 발생하지 않고 전체 자릿수가 막힘없이 표기됩니다.

### 4-2. 가로 모드 및 데스크톱 (min-width: 769px) 레이아웃 복원
* 넓어진 화면에서는 원스톱 삭제가 가능하도록 서랍 우측 영역에 **삭제 버튼(🗑️)이 온전히 flex 형태로 활성화**됩니다.
* 단축 문자가 다시 원래의 한글 풀네임 레이블인 **"평단가:"**, **"배당금:"**으로 자연스럽고 유기적이게 되돌아갑니다.
